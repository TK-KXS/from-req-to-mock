เอกสารนี้แปลงความต้องการทางธุรกิจของระบบสต็อกสินค้าเป็นข้อกำหนดทางเทคนิค เพื่อพัฒนา Web Application สำหรับอุปกรณ์พกพา (มือถือ/แท็บเล็ต) ที่ทำงานบน Huawei Cloud แทนการใช้ระบบ Excel เดิม

2. ผู้ใช้งานและสิทธิ์ (Users and Roles)

บทบาทสิ่งที่ทำได้
Adminดูข้อมูลทั้งหมด ปรับปรุงสต็อก และอนุมัติรายการสินค้าสูญหายหรือส่วนต่าง
Warehouse Staffบันทึกรับเข้า-จ่ายออก และบันทึกผลการนับสต็อกประจำวัน
Executive / Auditorดูรายงานได้อย่างเดียว ห้ามแก้ไขข้อมูล

3. ความต้องการเชิงฟังก์ชัน (Functional Requirements)

รหัสอ้างอิงความต้องการเกณฑ์การยอมรับ
TR-01REQ-01ระบบล็อกอินและกำหนดสิทธิ์ผู้ใช้งาน 3 ระดับ (Admin, Warehouse Staff, Executive/Auditor) แสดงเมนูตามบทบาทเข้าสู่ระบบด้วยแต่ละบทบาทแล้วเห็นเมนูตามสิทธิ์ถูกต้อง
TR-02REQ-02Admin ดูข้อมูลทั้งหมด ปรับปรุงสต็อก และอนุมัติรายการสินค้าสูญหายหรือส่วนต่างAdmin อนุมัติรายการส่วนต่างได้สำเร็จ
TR-03REQ-03Warehouse Staff บันทึกรับเข้า-จ่ายออก และบันทึกผลการนับสต็อกประจำวันStaff บันทึกรายการรับเข้าและจ่ายออกได้
TR-04REQ-04Executive/Auditor เปิดดูรายงานแบบอ่านอย่างเดียว ไม่มีสิทธิ์แก้ไขข้อมูลAuditor เปิดรายงานได้แต่ไม่มีปุ่มแก้ไข
TR-05REQ-05Dashboard แสดงภาพรวมสต็อกคงเหลือและสถานะสินค้าใกล้หมดDashboard แสดงยอดคงเหลือและสินค้าใกล้หมดถูกต้อง
TR-06REQ-06ระบบแจ้งเตือน Safety Stock Alert เมื่อสต็อกต่ำกว่าจุดเตือนแจ้งเตือนเมื่อสต็อกต่ำกว่าจุดเตือน
TR-07REQ-07Quick Search ค้นหาด้วยรหัส SKU หรือชื่อสินค้าค้นหาด้วย SKU และชื่อสินค้าได้ผลลัพธ์ถูกต้อง
TR-08REQ-08จัดการข้อมูลสินค้า: SKU, ชื่อ, หมวดหมู่, ราคา, จุดเตือนสต็อก และซัพพลายเออร์บันทึกและแก้ไขข้อมูลสินค้าครบทุกฟิลด์ได้
TR-09REQ-09รับเข้า/จ่ายออก ผ่านสแกนบาร์โค้ดหรือเลือกรายการ ระบุจำนวน และเลือกประเภทธุรกรรม (ซื้อเข้า, ขายออก, สินค้าเสียหาย, ส่งคืน)บันทึกรายการแต่ละประเภทธุรกรรมได้ถูกต้อง
TR-10REQ-10Cycle Count เริ่มรอบนับตามโซนหรือชั้นวาง และเปรียบเทียบยอดนับจริงกับระบบโดยอัตโนมัติระบบแสดงผลต่างระหว่างยอดนับจริงกับยอดในระบบ
TR-11REQ-11บังคับส่งคำขออนุมัติถึง Admin เมื่อผลต่างเกิน 5% หรือมูลค่าเกิน 1,000 บาท ก่อนตัดสต็อกจริงรายการที่เกินเงื่อนไขถูกบล็อกรออนุมัติก่อนตัดสต็อก
TR-12REQ-12รองรับการสแกนบาร์โค้ดผ่านกล้องมือถือ/แท็บเล็ต และเครื่องสแกนบาร์โค้ด USBสแกนผ่านกล้องและเครื่องสแกน USB ได้ทั้งคู่
TR-13REQ-13รายงานประวัติการเคลื่อนไหวสินค้าเข้า-ออก (รายวัน/รายเดือน) และรายงานมูลค่าสต็อกรวมในคลังเรียกดูรายงานแต่ละประเภทได้ถูกต้อง
TR-14REQ-14รองรับการส่งออกข้อมูล (Export) เป็นไฟล์ Excel และ CSVไฟล์ที่ Export เปิดได้และข้อมูลครบถ้วน
TR-15REQ-15ผลลัพธ์จากการสแกนบาร์โค้ดเสร็จภายใน 1 วินาที ทำงานบน Huawei Cloud เท่านั้น และสำรองข้อมูลทุกวันทดสอบเวลาสแกนไม่เกิน 1 วินาที และตรวจสอบ Backup รายวันสำเร็จ

4. ข้อมูล (Data)

ข้อมูลฟิลด์หลัก
ผู้ใช้งาน (User)รหัสผู้ใช้, บทบาท (Admin, Warehouse Staff, Executive/Auditor)
สินค้า (Product)SKU, ชื่อ, หมวดหมู่, ราคา, จุดเตือนสต็อก, ซัพพลายเออร์, ยอดคงเหลือ
รายการรับเข้า/จ่ายออก (Transaction)รหัสรายการ, SKU, ประเภทธุรกรรม (ซื้อเข้า, ขายออก, สินค้าเสียหาย, ส่งคืน), จำนวน, วันที่
การนับสต็อก (Cycle Count)โซน/ชั้นวาง, ยอดนับจริง, ยอดในระบบ, ผลต่าง, สถานะอนุมัติ
รายงาน (Report)ประวัติการเคลื่อนไหวรายวัน/รายเดือน, มูลค่าสต็อกรวมในคลัง

  • ภูมิภาคและ Availability Zone (region/AZ) สำหรับติดตั้งระบบ: [TBC: ภูมิภาคและโซนที่ต้องการ]

6. แพลตฟอร์มและการเชื่อมต่อ (Platform and Integrations)

  • อุปกรณ์: มือถือและแท็บเล็ต ใช้งานผ่าน Web Browser
  • การสแกนบาร์โค้ด: กล้องมือถือ/แท็บเล็ต และเครื่องสแกนบาร์โค้ด USB (REQ-12)
  • การส่งออกข้อมูล: ไฟล์ Excel และ CSV (REQ-14)
  • ทำงานบน Huawei Cloud เท่านั้น (REQ-15)
  • เชื่อมต่อ ERP / POS ภายนอก: อยู่นอกขอบเขตเฟสแรก แต่ออกแบบโครงสร้าง API รองรับไว้ล่วงหน้า [TBC: รายละเอียดโครงสร้าง API - Q-03]
